# Asteroids

A simple arcade game inspired by the classic Asteroids, built with **Python** and **Pygame**.

## Features
- Player movement and rotation
- Shooting and destroying asteroids
- Asteroids split into smaller pieces when hit
- Random asteroid spawning
- Collision detection and game over

## Tech Stack
- Python 3.13
- Pygame 2.6.1

## Getting Started

Clone the repository:
```bash
git clone https://github.com/MiraiChan/Asteroids.git
cd Asteroids
```

Install dependencies:
```bash
pip install pygame==2.6.1
```

Run the game:
```bash
python main.py
```

## Controls

| Key | Action |
|-----|--------|
| W / S | Move forward / backward |
| A / D | Rotate |
| Space | Shoot |
